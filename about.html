About this workspace

A Notion-like block editor built with BlockNote core v0.51.3, served as static files on Cloudflare Pages. No backend, no build step — open app.html or serve with python -m http.server.

Structure (chunked by standard)

  • app.html — main workspace (links to external assets)
  • index.html — landing page
  • css/theme.css — design tokens (--accent, shadows, radius)
  • css/app.css — layout, sidebar, panel, menus, editors
  • js/app-module.js — BlockNote init, IndexedDB, render, slash/context menus
  • components/ — reusable HTML partials (brandbar, sidebar-tools, tree, topbar, editor, menus)
  • pages/ — reserved for future routed pages (not required for Pages static hosting)

Cloudflare Pages notes

  • Root index.html is the Pages entry point.
  • No build command required; deploy the whole folder.
  • Assets in css/, js/, components/ are served statically.
  • CDN links to esm.sh work without additional configuration.

Theme

Soft neuromorphic monochrome: a single accent hue (#d85b45), paired soft shadows, gentle gradients, one neutral base tone. All tokens live in css/theme.css; derived shades are computed via color-mix where needed.
